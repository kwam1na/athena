Host interruption

A graceful lifecycle event reports paused; an unobserved crash or disconnect reports unknown lazily on status/resume. Neither advances the delivery checkpoint.

Safe takeover

Same-workspace reuse requires non-model-mintable graceful termination provenance (Tier 3). Otherwise the designed path quarantines the old workspace and resumes from the last trusted candidate in a fresh native worktree, at the cost of one typed operator confirmation per session boundary.

Failure and trust posture

Native grant enforcement

  • Grant, workspace, fence, and pinned root apply before model tools.
  • Missing, empty, unsupported, or failed grant application yields no mutation token.
  • Direct shell/MCP/provider bypass and protected-path writes are hostile qualification cases.

Stale-host containment

  • Every invocation is monotonically fenced against journal revision, candidate, policy, trust, and workspace.
  • Old-fence checkpoint, evidence, approval, and external-action submissions reject permanently.
  • Unverified prior workspaces are quarantined, never silently reused.

Dual revocation ceilings

  • Repository authority can narrow stage and finish-line powers immediately.
  • V1 product trust is local and operator-pinned (product-trust: local-digest / operator-pinned): a revocation list with a monotonic epoch and a no-downgrade high-water mark in the installation-scoped trust store; detached signing deferred to the first external adopter.
  • Revoked generations remain audit-retained but cannot admit, mutate, satisfy evidence, finish, or serve as executable rollback targets.

Human and privileged actions

  • Agents cannot mint termination provenance, sensitive approval assertions, or operator confirmations.
  • Merge/deploy/update/rollback credentials never enter model-driven tasks.
  • External actions bind both revocation epochs, candidate, fence, adapter, approval, and current evidence.
Local trust, no outage mode: there is no network trust authority and no metadata expiry, so local trust state is always current. Revocation immediately fences the invocation and enters security_blocked at any canonical recheck site; the exit always requires current trust state, full re-preparation, and revoked-era evidence invalidation — plus an explicit operator-asserted migration when the generation changed or the delivery is rebound.

Observable finish line

  • One install exposes an exact inspectable composition with no adopter-selectable skills/harness split.
  • One scoped handoff progresses through Plan → Work → Review → Compound and the policy-selected finish line without operator stage choreography while a supported host task is active.
  • The first Tier 1-qualified host (Claude Code default) proves model-external admission and host-native orchestration, the second host completes at its graded tier; the product launches no coding-agent subprocess, schedules no subagent, and creates or deletes no worktree.
  • Pause, unknown activity, cancellation, stale-task races, fresh-worktree takeover, and candidate mutation cannot accept stale evidence or duplicate external actions.
  • Every merge-ready result has criterion-mapped evidence, unanimous required review, a neutral tracked record, and compiled external-verifier proof.
  • Both repository-authority and product-trust revocation gate admission through terminal success; revoked generations enter a typed, actionable security block.
  • The trackerless product passes qualification for every claimed supported host and two policies, then Athena cutover; the later optional Linear composition reruns the full exact-composition and Athena gates before activation.
  • Athena retains its policy, executable adapters, Graphify/Convex/telemetry/reporting behavior, and pr:athena authority while shedding independent skills/harness lifecycle choreography.
