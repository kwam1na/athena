Minimum decisive capture

A single in-memory attempt slot records an id, load versus 1s-fallback, ready state, print invoked/returned, a side-effect-free return classification, compact print/unload ordering, closed state, timing, and completion reason.

At most one baseline row is written through the existing offline buffer, with 50 slots reserved for errors under offline pressure. The existing rejection listener attaches the snapshot only for the exact print signature and one unambiguous candidate within 60 seconds; a second sequential attempt forces an ambiguous result. No receipt or business content is collected.
