Stream the agent's provisional narrative to the reusable host

Created 2026-08-22Deepened 2026-08-22Type: featStatus: activeDepth: StandardSource: markdown plan

Stream the model's narrative live to the reusable agent host, for any profile, as explicitly provisional text; the committed artifact minted by completeRun stays the only released answer. The streamed text is the assistant thinking out loud (a different string from the narrative it later hands to completeRun), shown in a visibly provisional container, replaced by the committed answer at commit, deleted on every terminal cause, and accounted for with two markers on the turn binding. The change adds one runtime event, one minimal delete-only table with a small leaf helper module, two admitted entry points in turns.ts, and small hooks in the existing lifecycle clamp, release-suppression path, host finalization, scope removal, and repair sweep — and leaves the executor, budgets, grants, citations, read ports, registry conformance, and the completeRun transaction untouched.

Prerequisite. The agent-harness foundation batch (V26-1259, V26-975, V26-1261, V26-1262, V26-1263, V26-1264, V26-1265, V26-1267, V26-1268, V26-1272, V26-1273; integration branch codex/agent-harness-foundation-delivery) is merged to main. Paths are repo-relative under packages/athena-webapp/ unless stated, and name modules that branch lands.

Problem frame

The foundation buffers the narrative server-side and streams only server-authored milestones so that release is one reauthorized transaction and revocation before it is fully recallable. The cost: a real provider turn shows nothing for several seconds, then the whole answer. Operators expect to watch an answer form. Treating streamed text as a provisional exposure class with its own truthful markers lets operators watch an answer form without weakening release. This plan amends the foundation's R16/R18 exposure semantics and records the amended invariant.

Requirements

  1. R1 Narrative streams for any profile whose policy enables it, through the reusable host; no surface-specific branch.
  2. R2 Provisional text sits in a persistent, distinct container whose copy says it is not verified and must not be acted on; never citation-bearing, never a citation source, never in history or a prompt, never promoted to standard retention.
  3. R3 The committed artifact is the only released answer; because completeRun is a mid-turn tool call whose narrative is an independent string, the provisional text is replaced, not morphed, and the operator is told it may differ.
  4. R4 Deleted on every terminal cause: the lifecycle's terminal clamp for non-completed terminal statuses (cancel, failure, kill switch, fence repair; in that transaction), suppressReleaseWithCtx for post-commit revocation, the host's finalizeTurnWithCtx transaction at the end of every driven turn (successful commit and commit-then-provider-failure), and scope removal's own scope-indexed delete. A row past its short expiry is reported as stalled by the preview — a servable arm with no text, not a refusal — dropped client-side once the returned expiry passes, and deleted by the repair sweep. The preview query never writes.
  5. R5 The turn binding records provisionalReleasedAt (first text readable) and provisionalViewedAt (best-effort client acknowledgement, weaker than operatorViewedAt; refused unless provisionalReleasedAt is already set). The turn-scoped projection derives provisionalExposurePresumed and revokedAfterProvisionalExposure (the existing terminalRevoked predicate or release suppression). Markers are irrevocable and reachable through a turn-keyed entry point for zero-attempt turns.
  6. R6 One new normalized runtime event (narrative_delta) with a protocol-version bump, emitted by both the contract fake and the Convex Agent adapter and proven by the shared contract suite; no runtime-native type leaves the adapter directory.
  7. R7 No Convex Agent component stream persistence; the component allowlist (input | turn | projection) is unchanged.
  8. R8 Provisional text reaches the browser only through an Athena-owned reactive query separate from the turn view that reauthorizes on every read and returns not_found until ownership is established; the flush is a host-only internal mutation (it authorizes the grant's pinned operator, not its caller); streaming writes the binding only once (provisionalReleasedAt), never per delta, and never touches the run record.
  9. R9 Rendering uses the foundation's inert AthenaAgentSafeText in a provisional mode (paragraphs, lists, inline spans only; rules dropped, headings downgraded, quotes and fenced code flattened), re-parsed from the whole buffer every render so every prefix is inert; no browser-side persistence; the panel's single scroll container follows the growing text only while the operator is at the bottom; the live region announces at most one coalesced change per draft and focus moves only on a terminal hostState transition, onto the answer heading on commit, or once onto a mid-run withdrawn notice — never on streaming, reset, pause, or stall, and never twice for the same terminal outcome.
  10. R10 Enablement is a required, validated, kernel-visible per-profile policy (provisional_streaming | buffered) in the compatibility digest, enforced server-side by the flush (read from the digest-pinned registry profile after reauthorizeGrantWithCtx) and reported by the preview from the live registry profile (both drift directions are fail-safe); proven end to end by a second, buffered test profile alongside the existing shared test profile (which stays provisional_streaming because every host and turn test pins it).
  11. R11 Deploys behind the existing one-command compatibility fence.
  12. R12 The foundation's "no partial narrative reaches the browser" tests are rewritten to the amended invariant — "the narrative never enters Athena's durable record, projected history, a citation, or a prompt, and never survives a terminal cause" — not deleted.

Scope boundaries

  • No streaming of tool-call arguments, program source, capability results, reasoning, or any non-text part.
  • No per-chunk citation validation or streamed citations.
  • No change to operatorViewedAt, the completeRun transaction, executor, budgets, grants (including the closed DelegatedAuthorityPurpose set — the flush reuses the existing release purpose; accepted), read ports, or capability conformance.
  • No component stream tables, saveStreamDeltas, syncStreams, or @convex-dev/agent/react in the browser; no second runtime; no TanStack-path streaming.

Deferred to follow-up work

  • Reveal smoothing tuned from measured latency; provider finish reasons as a stop reason; a general cancel-poll shortening; a boundary rule banning react-markdown from the agent host.
  • Faster closure of a run left at running by a crashed host. The foundation's stale-binding sweep now fails such runs (turn_host_stalled) at the 15-minute abandon window; this plan bounds the readability of the draft much tighter — the row's 5-minute expiry, the client-side drop, and the repair sweep — and does not shorten the run's own window.

Open questions

Resolved during planning

  • Persistence: a minimal delete-only table plus a leaf helper module (prompt-payload reuse rejected for the sweep side effect; helper placed to avoid import cycles).
  • Ordering: single-flight flushes instead of a compare-and-set key; drain at the completeRun request.
  • Dead hosts: expiry refused server-side, dropped client-side on the returned clock, deleted by the repair sweep.
  • Deletion timing: clamp (non-completed), suppressReleaseWithCtx, finalizeTurnWithCtx, scope removal; never the commit transaction.
  • committing: derived from the existing finalizing milestone compared against the row's updatedAt, both stamped from the host's one now; no new server write.
  • First-token latency: awaiting_first_text (milestone-only view) until provisionalReleasedAt exists; stalled only after it; a buffered profile is the standing disabled state.
  • Host typing: provisional presentation is a separate provisionalState field; the kernel's AgentHostState union is untouched.
  • Re-prepare egress patching: dropped — unreachable, and the invocation row is provider evidence.
  • Reset across tool steps and resumed attempts: yes, one draft ordinal each, client-detected.
  • Deploy posture: fence → deploy → direct-harness smoke + adapter smoke → enable → one operator turn (non-prod driver; prod: first monitored turns).

Deferred to implementation

  • Coalescing cadence (start ~200 ms / punctuation; tune from measured latency). The flush-before-tool_call_requested rule in U2 is fixed, not tunable.
  • Streaming mock chunk shape in the contract harness and smoke action.
  • Exact copy per host state in AthenaAgentPresentationAdapter.ts following docs/product-copy-tone.md.

High-level design

Directional guidance for review, not implementation specification.

Provider stream → adapter forwards only text-delta parts (others dropped) and coalesces them → narrative_delta { draftOrdinal, text } via hooks.onEvent → runtime host → single-flight flush in turns.ts, via the leaf helper (policy check, reauthorize, refresh expiresAt, stamp egress class, overwrite text; delete on refusal) → provisional row → getTurnNarrativePreview returns streaming {released, text, truncated, draftOrdinal, updatedAt, expiresAt, ttlMs}, or disabled/awaiting_first_text/stalled/superseded {released}, or withdrawn {reason, released}, or not_found → reusable host, which calls acknowledgeProvisionalView (full reauthorization) on first paint. At the tool_call_requested completeRun event the host awaits the in-flight flush and stops scheduling; the pane shows committing from the existing finalizing milestone. If the commit succeeds, the commit transaction itself stays untouched (the clamp skips completed) and finalizeTurnWithCtx deletes the row, and the preview derives superseded so the host swaps to getTurnAnswer; if the commit is denied, fails retryably, or is rejected as a protocol violation, flushing resumes with a new draftOrdinal. Cancel, failure, kill switch, and fence repair delete the row inside the lifecycle clamp in the same transaction; post-commit revocation deletes it in suppressReleaseWithCtx; scope removal deletes it by its own scope-indexed delete; a dead host is bounded by the row's expiry, the client-side drop, and the repair sweep.

U2 · Convex Agent adapter streaming path

Approach

Call the stream entry point with delta persistence off; forward only text deltas to the narrative; observe control parts for lifecycle (error → terminalize failed with the provider-failure code, abort → canceled, step markers → new draftOrdinal); coalesce, but always flush the coalescer before emitting tool_call_requested — the flush lives at the top of dispatch() (reached from the native tool's execute callback and from repairToolCall), and because a new step only begins after a tool call, that single flush also guarantees no text is misattributed across a step boundary, so the stream-consumer loop needs no flush of its own — (normative, not a tuning knob: a short preamble followed by an immediate tool call must reach the host before the tool-call event, or the narration gate and awaiting_first_text both misread the opening phase); emit through emit; drain the stream so the last step's usage and text are observed before terminalize; keep per-step usage through usageHandlerFor and abort through the existing signal.

Test scenarios

  • Happy path: a scripted stream emits gapless deltas per draft, no duplicated text, then turn_completed with the full narrative.
  • Integration: with deltas emitted, the component stream table is still empty and the turn message is empty until projection.
  • Error path: reasoning/tool-input parts never appear in a delta; abort mid-stream → turn_completed{canceled} and no later deltas; a mid-stream error part → turn_completed{failed} with the provider-failure code and no later deltas (never completed with partial text).
  • Edge case: empty stream → zero deltas, empty narrative, per-step usage unchanged; a tool step advances draftOrdinal; ordering within a draft is the envelope's sequence.
  • Integration: the shared suite case passes against the adapter under convex-test; the deployed smoke emits at least one delta with the mock; and the gate for starting U3–U5 is production-shaped, not the generic smoke (whose single-tool prompt is exactly the configuration that suppresses narration): one real Daily Operations operator turn on the dev deployment through the existing non-prod driver (convex/agentHarness/evals/directHarness.ts's startOperatorTurn, real prompt, real completeRun), read through a single console.log line that driveTurn in runtimeHost.ts emits at the end of every driven turn with the ordered event kinds it already collects (run-length collapsed — narrative_delta×41 — so hundreds of deltas stay legible) plus two elapsed values — milliseconds to the first narrative_delta (a new timings.firstDeltaMs, stamped by the host on the first delta) and milliseconds to completion (the existing timings) (the drive report itself never leaves the process — driveTurn is a scheduled internalAction whose return value is discarded — so the log line, visible via bunx convex logs on dev, is the read path, and it doubles as the first-turn monitoring hook the rollout asks for): the line must show narrative_delta before the first tool_call_requested (read with bunx convex logs --history <n>, the repo's own precedent, so the check does not depend on tailing order); if the provider narrates nothing, the directive is tuned before any persistence work starts.

Approach

  • Flush (host single-flight, named ref): refuse for buffered (policy from the digest-pinned registry profile); truncate text at the 16 KiB cap inside the flush — at the last whole codepoint at or below the cap, never a raw byte offset, so the stored text stays well-formed for the per-frame re-parse — and set truncated (the cap is enforced server-side, not trusted from the host); return { outcome: "stored" | "refused", truncated } (the host needs refused to drop the chain; truncated is informational); overwrite text for the current draft; reauthorizeGrantWithCtx; refresh expiresAt; stamp the egress class on insert (refuse without it); set provisionalReleasedAt once; insert only while the run is running and operatorReleaseCommittedAt is unset; delete on any refusal.
  • Quiescence: at tool_call_requested(completeRun) set the stop flag, then await the in-flight flush; resume with a new draft on any non-success outcome.
  • No pause mode and no keep-alive: the host keeps its normal coalesced flush cadence for the whole draft, truncated or not (the server cap makes the overwrite idempotent and each flush refreshes expiresAt); the only time text flushes stop is the completeRun stop flag, and if a denied commit is followed by a tool-only tail longer than the TTL the row simply ages into the non-terminal stalled and recovers on the next draft — turn elapsed is bounded at ~90 s on both shipped profiles against a 5-minute TTL, so this is unreachable today and not worth a second flush mode.
  • Preview: returns the non-terminal disabled state for a never-released buffered turn and withdrawn/policy_disabled after a release; returns released, updatedAt, and ttlMs with expiresAt; awaiting_first_text while provisionalReleasedAt is unset.
  • Acknowledge: refuses unless provisionalReleasedAt is set; mirrors both of acknowledgeTurnAnswer's refusal branches — revoked authority on the caller's own turn, and egress_beyond_authority for a downgraded owner — and deletes the row on either; pre-ownership refusals write nothing.
  • Deletion: clamp (non-completed); suppressReleaseWithCtx (outside the guard); finalizeTurnWithCtx (above already_terminal); scope removal; repair-sweep expiry phase (logs its count when nonzero).
  • Preview ladder: the first rungs delegate to the existing reauthorizeTurnAccess in the same file (delegated operator → binding/store → grant owner, not_found until here → live authority incl. enablement) rather than a second hand-rolled ladder → epoch fence via the already-imported checkRunEpochFenceWithCtx (a digest-moving deploy withdraws immediately instead of waiting for the next flush or the fenced-run repair) → profile policy (disabled, non-terminal) → egress rank (compared, after the same normalizeEgressClass read the flush uses, against requestSummary.egressClass on the write-once provider-invocation row — by_runId, inserted once in prepareTurnWithCtx; before that row exists the turn is still queued, nothing has been released, and the rung is skipped so the ladder falls through to awaiting_first_text rather than a false withdrawn — never against the provisional row, so the verdict survives the row's deletion and a remount after an egress downgrade still shows withdrawn, not stalled) → not abandoned/suppressed → run state (running continues; completed → superseded, because completeRun flips the run mid-turn and the row survives until finalizeTurnWithCtx, so a successful commit must never read as a withdrawal; canceled/failed → withdrawn) → expiry; return the discriminated union (bare not_found; withdrawn with only reason and released; metadata and text only on servable arms) with a closed reason on withdrawn and released on every post-ownership state (buffered after a release → withdrawn/policy_disabled, never disabled); never write.
  • Acknowledge: full turn reauthorization, owner only, provisionalReleasedAt required, first-write-wins provisionalViewedAt.
  • Exposure: two markers + derived fields via resolveTurnExposure, reachable through describeTurnExposure.
