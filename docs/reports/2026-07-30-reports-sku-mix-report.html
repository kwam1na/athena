Executive Summary

Reports now pairs its operating-day table with a product-unit mix for the same selected date range. Operators can identify the products responsible for unit volume without leaving the Days workspace.

The mix is calculated by an authenticated, bounded Convex read model. It returns the top 5 products and an explicit Other SKUs remainder, so a dense range fails rather than silently presenting incomplete data.

Mental Model

The date range is the shared source of truth. It feeds two independent views: daily totals for chronology and an aggregated SKU view for composition. Selecting a day narrows that shared range; the existing date link still drills into Items.

SKU identity lookup happens after aggregation. The system reads SKU-day rows, totals units per SKU, chooses the visible leaders, then resolves only those labels.

date range -> listDays -> day table
           -> listRangeSkuMix -> aggregate reportSkuDay -> top 5 + Other -> chart and legend

Behavior and Boundaries

The route no longer exposes the legacy custom-range panel or its URL state. The Days range defaults to a rolling 14 days and has an explicit reset action.

The mix is units-only. It does not summarize revenue, profit, returns, inventory availability, or zero and net-negative SKUs. Individual shares are rounded, so displayed percentages can differ slightly from 100% in total.

  • Server-side access plus range order and 92-day span validation run before data is read.
  • A 5,000-row limit plus one sentinel rejects an oversized result rather than truncating it.
  • Only the top 5 product identities are hydrated; all remaining positive-unit products are grouped as Other SKUs.
  • The chart provides an accessible legend, tooltip, empty state, reduced-motion behavior, and a static fallback when intersection observation is unavailable.
