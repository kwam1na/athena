What this candidate delivers

Three narrow Athena repairs keep test and development-server caches out of frozen dependency inputs. The storefront fallback selects its existing unit profile, temporary membership tests own their caches, and storefront Vite writes to a separate declared cache directory.

The installed delivery product continues to verify source and dependencies. This candidate does not activate affected validation or complete V26-2071. The full qualification corpus, trusted hosted health, cold verification, performance comparisons, rollback and final activation remain required.

Why successful commands still failed

Hosted health run 35516273775 recorded eight failed attempts after their commands exited zero. Post-command verification reported check_snapshot_drift: the frozen workspace no longer matched its captured inputs. A green test process alone could not authorize admission.

The artifact did not retain changed-path inventories. Focused investigation reproduced three cache-write mechanisms, but does not establish the exact cause of every historical hosted failure. Those failures remain open pending current qualification.

Inputs stay fixed; outputs have named homes

A validation command receives fixed source and installed dependencies, plus narrowly declared places to write results. A cache is still an output even when a tool chooses its location automatically. Temporary fixtures also need their own output locations: a dependency symlink can send writes outside a fixture that is later deleted.

Vite's optimized modules are executable generated files. Fresh native workspaces and a separate cache directory keep those writes from weakening verification of installed dependencies.
